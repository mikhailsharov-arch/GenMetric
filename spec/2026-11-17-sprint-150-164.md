## Что решили

**П. 150 — частоты подсказок при пересохранении.** `forget_entry` снимает
всё, что прибавляет `save_entry_in_tx`: звание (вид — по причту и полу,
написание — `rank_canonical`, то же, что у `remember`), НП, причину смерти,
родство, «каким браком», вероисповедание. Частный обход в `replace.rs`
удалён. Уже завышенное у Романа (1654 «Взять правку во всех») не
пересчитываем: в частотах смешаны записи и архив Excel.
Критерий: тест `records::resave_keeps_counts` — три пересохранения не меняют
частот, удаление записи возвращает частоты к прежним и убирает опечатку из
перечня.

**П. 151.** Запрос дела, года книги и раздела записи — блок
`entry_place_in_book`, общий для сохранения и удаления.

**Пп. 152–157 — окно сверки правок слияния.** Отличия считаются по полям
(`merge::diffs`), а не разбором текста строки: правка — «поле: «у вас» →
«у помощника»» без того, у кого (`Diff::key`). Окно получает для каждой
несделанной строки `EditView` (заголовок записи, правки с перечнем людей,
прочее) — `review_list` строит его заново по нашей записи, какой она стала,
и записи помощника из `merge_origin.pending`. Поэтому:
- группа — все строки, где есть эта правка, даже с другими отличиями (1.6);
- запись, поправленная после слияния так, что правки больше нет, в группу
  сама не попадает, а массовое действие её отклоняет;
- «Взять правку во всех» (`merge::piece_many`, `take = true`) переносит в
  нашу запись только поля этой правки (`copy_entry_field`,
  `copy_person_field`; ИОФ — с современным написанием и полом; НП — через
  `our_place`) и пересохраняет её (`save_entry_in_tx`). Не осталось
  нерешённого — строка в сделанных; всё взято — отпечаток помощника принят,
  как у `take`;
- «Оставить мою во всех» (`take = false`) пишет ключ правки в
  `review_item.kept` (новая колонка, без NOT NULL и DEFAULT — обновление
  добавит её само); строка без нерешённого — в сделанных, запись не меняется;
- «Взять правку» в строке — по-прежнему запись целиком (`take`).

Окно шлёт строки частями по 25 (`merge_piece_many`, копия прихода — перед
первой частью «взять»), между частями — полоса хода (п. 152; только если
дольше 0,5 с). Итог — зелёная плашка наверху до закрытия окна, копия —
именем файла и «Показать в папке» (п. 153). Шапка и нижняя панель — на месте,
прокручивается только список (п. 154). Записи группы — переключателем внутри
блока, своя прокрутка (п. 155). Строка — заголовок записи жирным, каждая
правка строкой с перечнем людей, без «и ещё отличий»; предупреждение
«целиком» — один раз в шапке раздела; кнопки — под текстом (п. 156).
Критерий: тест `merge::one_edit_in_many` (правка НП у отца и матери плюс
страница: «взять» НП — строка остаётся только со страницей, «оставить»
страницу — строка в сделанных, страница наша); `merge_story` — чужая правка
и поправленная после слияния запись отклоняются; стенд `s79`, раздел 4.

**П. 158 — село, уезд, губерния у дела своего года.** `case_spread_parish`
разносит только индексатора, ключ прихода и пустой архив. Ключ прихода
по-прежнему общий (частоты «по приходу» — общие). Существующим приходам
переносить нечего: прежний разнос уже записал значения в каждое дело.
Слияние: дело нового года — с церковью, селом, уездом, губернией помощника
(пустое — от нашего первого дела).

**П. 159 и П1 — подсказка НП.** `place_order`: сначала пункты, у которых с
набранного начинается название без приставки, внутри — по частоте, при

волость, уезд, губерния; пустое пропускается; не помещается — многоточие и
полный текст при наведении.

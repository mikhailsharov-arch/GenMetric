## 1. Цвет строк по полу в списке «Набрано» (задача 4)

Замечание Романа 2 к сборке 21.10: строки мужчин — бледно-голубые
(`#E3F2FD`), женщин — светло-розовые (`#FCE4EC`).

**Что делаем.**
- Пол строки решает одна чистая функция `rowSex` (в `src/count.ts`, рядом с
  правилами счёта по полу) → `"m" | "f" | null`:
  - рождения: по колонке номера — `no_male` → `m`, `no_female` → `f`
    (номер ложится в колонку по полу ребёнка); номера нет — `null`;
  - смерти: по полу умершего (`deceased_gender` из `entry_list`: «М»/«Ж»);
    пола нет — по колонке номера, как в рождениях; нет ни того ни другого —
    `null`.
- `BirthForm.tsx` и `DeathForm.tsx`: у `tr` списка класс `sex-m` / `sex-f`
  вдобавок к `editing`.
- `src/styles.css`: `.facts.saved tr.sex-m td { background: #E3F2FD; }`,
  `tr.sex-f td { background: #FCE4EC; }`. Правило `tr.editing td` стоит
  **после** них и остаётся жёлтым — выделенная строка видна поверх цвета.
- Без пола (`null`) — строка без цвета, как сейчас.

**Чего не делаем.** «Браки» не красятся: в строке двое. Запрос `entry_list`
и схема базы не меняются (пол умершего уже в запросе).

**Уточнение при работе.** Пол умершего Rust читал (колонка 17), но окну не
отдавал — он шёл только на полное ИОФ младенца. Поэтому в `EntryBrief`
(`main.rs`) добавлено поле `deceased_gender`; шим стенда отдаёт все колонки
запроса и не меняется. Форма «Смерти», дописывая только что сохранённую
строку в список сама, ставит ей тот же пол. Функция — `rowSex` /
`rowSexClass` (`src/count.ts`), пол — `Sex` («М»/«Ж»), как у счёта.

**Найдено попутно (не входит в спринт):** «весь перечень» ▾ у поля НП
показывает не больше 200 пунктов (`clamp(1, 200)` в `suggest`) — Бэклог р. 3,
п. 3.

## 2. Подсказка населённого пункта с одной буквы (Бэклог р. 2, п. 1)

С одной буквы пункты ищутся по вхождению, и SQL берёт 200 самых частых до
сортировки `place_order` (`first_limit` в `src-tauri/src/main.rs`, метка
`shortcut:`). У Романа 197 пунктов: с двухсотого ни разу не набранный пункт
может выпасть из подсказки на первую букву.

**Решение:** предел для пунктов — 5000 (справочник прихода на порядок
меньше; выборка идёт по индексу и сортируется в Rust — см. «Находки
агентов»: для этого склейка и сортировка переведены на ключ один раз на
строку). Метка `shortcut:` и комментарий — с новым пределом. Копия в шиме
стенда (`_стенд/dev/tauri-shim.ts`, `kind === "place" ? 200`) — то же
число. Сколько строк видит человек, не меняется: это решает `limit` после
сортировки.

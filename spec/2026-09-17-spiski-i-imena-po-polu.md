# Спецификация: списки только по набору, имена по полу из частот, Shift+Enter

По замыслу `intent/2026-09-17-otchyot-romana-15-09.md`.

## 1. Список подсказок открывается только на набор с клавиатуры

Причина «нескольких списков разом»: `Suggest` и `IofField` запрашивали
подсказки на любое изменение значения, включая программное — выбор персоны
подставлял НП, звание и жену, и у каждого поля открывался список. Теперь
флаг «набрано с клавиатуры» ставится в `onChange` поля; без него эффект
список не открывает и не закрывает (закрывать нельзя: у восприемника пол
приходит после разбора и перезапускает эффект).

Критерии: стенд `_стенд/lists.mjs` с настоящим архивом — после выбора
персоны отца открытых `.suggest` ноль, НП/звание/жена подставлены. То же
для выбора причта из списка. Регресс в `scripts/test_incidents.py`.

## 2. Имена и отчества из частот — по полу

`suggest_ranked` получил место `{usage_gender}`; для имён и отчеств туда
подставляется блок `usage_gender_filter`: значение из `usage_stat` берётся,
если словарь знает его с нужным полом или не знает вовсе. Подстановка
одинаково в `main.rs`, `db/test_suggest.py`, `dev/tauri-shim.ts`.

Критерии: `db/test_suggest.py` 4б — частый «Ананий» матери не предлагается,
частая «Анна» идёт первой, неизвестное словарю имя показывается обоим.

## 3. Shift+Enter — предыдущее поле

Во всех полях формы и шапки; стрелка вверх — как раньше. В инструкцию.

## Отложено на следующую сессию

Восстановление стр./счёта/месяца при запуске — `spec` отдельно.

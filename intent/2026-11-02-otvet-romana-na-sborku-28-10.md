## Проверено по коду (02.11)

- Карточка нового пункта (`src/PlaceCard.tsx`): тип — `defaultType`, иначе
  тип последнего пункта, иначе «д.»; набранное название целиком уходит в
  «Название», приставка типа не разбирается.
- Возраст жениха и невесты — целое `person_mention.age_years`; у смерти для
  книжного написания есть `age_text` («1,5 мес»), у браков он не
  используется. Импорт Excel-индексатора читает возраст брака целым
  (`import.rs`, `int(row, c + 5)`): «17,5» из файла тоже теряется.
- Возврат фокуса при наборе из окна скана на Windows подтверждён его живым
  тестом (бэклог п. 98 — закрыт).

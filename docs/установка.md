# Как установить сборку для тестирования

Программа пока в разработке. Каждая новая сборка появляется по одной и той же ссылке:

**https://github.com/mikhailsharov-arch/GenMetric/releases/tag/latest-test**

Ссылка не меняется — можно добавить её в закладки и просто заходить туда за свежей версией.

## Windows

Скачайте файл с расширением `.msi` (или `.exe`, если msi чем-то не подошёл) и запустите его.

Windows покажет синее окно **«Система Windows защитила ваш компьютер»**. Это не значит, что с файлом что-то не так: так система реагирует на любую программу, у которой нет платной цифровой подписи. Нажмите **«Подробнее»**, затем появившуюся кнопку **«Выполнить в любом случае»**.

Если антивирус удалил файл, добавьте папку загрузок в исключения либо скачайте заново и выберите «Оставить файл». Причина та же — отсутствие подписи, а не содержимое программы.

## macOS

Скачайте файл `.dmg`, откройте его и перетащите GenMetric в папку «Программы».

При первом запуске macOS скажет, что программа **«не может быть открыта, так как её автор не установлен»**. Нажмите **правой кнопкой** (или Control + щелчок) по значку программы и выберите **«Открыть»**, затем в появившемся окне снова **«Открыть»**. Достаточно сделать это один раз.

Если система пишет, что файл повреждён, откройте Терминал и выполните:

```
xattr -dr com.apple.quarantine /Applications/GenMetric.app
```

## Почему появляются предупреждения

Чтобы их не было, нужна платная цифровая подпись: у Microsoft это сертификат разработчика, у Apple — участие в программе разработчиков. Для бесплатной программы это заметные ежегодные расходы, и решение по ним пока не принято. На безопасность самой программы это не влияет: исходный код открыт и лежит в этом же репозитории, а сборки делаются автоматически из него — никто, включая авторов, не может подменить содержимое незаметно.

## Что сейчас умеет сборка

Это по-прежнему проверочная сборка, а не рабочая версия: сохранять записи она не умеет. Но по замечаниям Романа в ней исправлено и добавлено следующее.

**Список подсказок больше не залипает** — после выбора значения он закрывается.

**Переход по Enter и стрелке вниз.** Пока список подсказок открыт, стрелки выбирают вариант, а Enter подставляет его. Когда список закрыт, Enter и стрелка вниз переводят фокус на следующее поле — как было в Excel-Индексаторе.

**Единое поле ИОФ вместо трёх.** Наберите, например, `Иван Семенов Карсаков`. Подсказки идут пословно: первое слово — по именам, второе — по отчествам, третье — по фамилиям. Под полем показывается разбор: что программа считает именем, отчеством и фамилией, какой пол определила и какое современное написание предлагает.

**Справочники стали вдвое полнее** — в поставку вошли перечни, наросшие за время работы по Борисоглебскому приходу: 123 мужских звания вместо 51, 76 причин смерти вместо 40, 76 женских званий вместо 41.

**Что проверить и о чём рассказать:**

Правильно ли разбирается ИОФ на ваших настоящих записях. Особенно интересны случаи, где программа ошиблась: редкие отчества, двойные фамилии, прозвища.

Устраивает ли пословная подсказка или привычнее искать персону целиком.

Не мешает ли, что после выбора подсказки автоматически добавляется пробел.

Не сбивает ли с толку переход по Enter, когда список закрыт.

Замечания присылайте Михаилу — с указанием версии Windows или macOS.

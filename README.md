# GenMetric

Настольная программа для индексации метрических книг — под Windows и macOS.

Индексация это перенос рукописных церковных записей XIX — начала XX века в таблицу: рождения, браки, смерти, имена, населённые пункты, звания, даты. Работа долгая: у опытного индексатора один приход занимает около полугода. GenMetric делается, чтобы её ускорить.

**Статус: в разработке.** Рабочей версии пока нет, устанавливать нечего. Готов слой хранения данных со справочниками.

## Зачем ещё одна программа

Сейчас сообщество индексаторов работает в Excel-файле с макросами. Он хорош и проверен годами, но упирается в возможности электронной таблицы: часть полей приходится проскакивать вручную, подсказки выдаются по алфавиту вместо частоты употребления, данные о матери не подтягиваются по уже введённому отцу.

Отсюда главная задача GenMetric — **автозаполнение**. Не «Excel, но красивее», а программа, которая помнит всё, что вы уже набрали, и предлагает это раньше, чем вы допечатаете слово.

Что из этого следует:

Подсказки ранжируются по частоте, а не по алфавиту, причём в порядке: сначала то, что встречалось в текущем деле, затем в текущем приходе, затем во всей вашей базе, и только потом словарные варианты.

Персона подставляется целиком: начали писать «Карс» — программа предлагает «Карсаков Иван Семёнович, крестьянин, деревня Фетинино» со всеми атрибутами сразу.

Ввели отца в записи о рождении — программа находит в базе его жену и предлагает подставить мать одним нажатием.

Шапка дела (архив, фонд, опись, дело, приход, год, причт) вводится один раз и держится неизменной, пока вы сами её не поменяете.

Порядок полей на форме повторяет порядок, в котором сведения написаны в самой книге, чтобы не приходилось забегать глазами вперёд и возвращаться.

Работа целиком с клавиатуры. Окно узкое и вытянутое, чтобы стоять слева, пока справа открыт скан.

## Что программа делать не будет

Распознавать рукопись. Это осознанное решение: существующие решения для русской скорописи XIX века дают черновик, править который дольше, чем набрать заново.

Заменять просмотрщик сканов. Вы смотрите скан привычной программой, GenMetric просто не занимает весь экран.

## Выгрузка данных

Результат выгружается в формате сервиса [Familio](https://familio.org) — чтобы проиндексированные книги попали в общую базу и другие исследователи смогли найти там своих предков, — и в Excel для собственной работы.

## Устройство репозитория

    db/                  слой хранения: схема, справочники, сборка базы
      schema.sql         схема SQLite
      seed/              справочники в текстовом виде (CSV)
      build_seed.py      сборка стартовой базы из CSV
      verify_seed.py     проверки: 36 штук
      tools/             разовые утилиты переноса данных

Собрать базу и проверить её:

```bash
python3 db/build_seed.py
python3 db/verify_seed.py
```

Нужен Python 3.9 или новее. Для сборки базы сторонние библиотеки не требуются.

## Готовые сборки

**[Скачать последнюю сборку](https://github.com/mikhailsharov-arch/GenMetric/releases/tag/latest-test)** — Windows и macOS.

Ссылка постоянная: сборка обновляется автоматически после каждого изменения в коде, адрес при этом не меняется. Как установить и что делать с предупреждением системы о неизвестном разработчике — в [инструкции](docs/установка.md).

Сейчас это сборка для проверки работоспособности, а не рабочая версия: формы ввода записей в ней пока нет.

Скомпилированные файлы в репозитории не хранятся — только в разделе выпусков, и собираются автоматически из исходного кода.

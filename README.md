# GenMetric

Настольная программа для индексации метрических книг — под Windows и macOS.

Индексация это перенос рукописных церковных записей XIX — начала XX века в таблицу: рождения, браки, смерти, имена, населённые пункты, звания, даты. Работа долгая: у опытного индексатора один приход занимает около полугода. GenMetric делается, чтобы её ускорить.

**Версия 1.0.1** (18 ноября 2026). Программа в работе: заказчик ведёт в ней чистовую индексацию, набрано больше 20 000 записей. Что менялось — в [CHANGELOG.md](CHANGELOG.md).

## Зачем ещё одна программа

Сейчас сообщество индексаторов работает в Excel-файле с макросами. Он хорош и проверен годами, но упирается в возможности электронной таблицы: часть полей приходится проскакивать вручную, подсказки выдаются по алфавиту вместо частоты употребления, данные о матери не подтягиваются по уже введённому отцу.

Отсюда главная задача GenMetric — **автозаполнение**. Не «Excel, но красивее», а программа, которая помнит всё, что вы уже набрали, и предлагает это раньше, чем вы допечатаете слово.

Что из этого следует:

Подсказки ранжируются по частоте, а не по алфавиту, причём в порядке: сначала то, что встречалось в текущем приходе, затем во всей вашей базе, и только потом словарные варианты.

Персона подставляется целиком: начали писать «Карс» — программа предлагает «Карсаков Иван Семёнович, крестьянин, деревня Фетинино» со всеми атрибутами сразу.

Ввели отца в записи о рождении — программа находит в базе его жену и предлагает подставить мать одним нажатием.

Шапка дела (архив, фонд, опись, дело, церковь, село, год) вводится один раз на год книги и держится неизменной, пока вы сами её не поменяете. Причт запоминается и подставляется в следующую запись.

Порядок полей на форме повторяет порядок, в котором сведения написаны в самой книге, чтобы не приходилось забегать глазами вперёд и возвращаться.

Работа целиком с клавиатуры. Окно узкое и вытянутое, чтобы стоять слева, пока справа открыт скан.

## Что программа делать не будет

Распознавать рукопись. Это осознанное решение: существующие решения для русской скорописи XIX века дают черновик, править который дольше, чем набрать заново.

Быть полноценным просмотрщиком сканов. Скан страницы (JPG, PNG, TIFF, PDF) открывается рядом с формой или отдельным окном и листается вслед за записью, но обработки изображений в программе нет.

## Что ещё умеет

- Поиск персоны по всей базе и досье: семья, рождение, браки, смерть.
- Импорт из Excel-индексатора и из шаблона Familio.
- Несколько приходов, у каждого свой файл; слияние с файлом прихода помощника со сверкой его правок.
- Найти и заменить в записях, объединение населённых пунктов, очистка неиспользуемых значений справочников.

## Выгрузка данных

Результат выгружается в формате сервиса [Familio](https://familio.org) — чтобы проиндексированные книги попали в общую базу и другие исследователи смогли найти там своих предков, — и в Excel для собственной работы.

## Устройство репозитория

    src/                 окно программы (React, TypeScript)
    src-tauri/           программа на Rust (Tauri 2)
      core/              логика без окна: запись, слияние, импорт, выгрузка, поиск
    db/                  схема SQLite, запросы (statements.sql), обновление базы, справочники
    scripts/             проверки и сквозной сценарий для Windows
    intent/              что просил заказчик, его словами
    spec/                что решено сделать и как это проверить

Как собрать и проверить — команды в [CLAUDE.md](CLAUDE.md), раздел «Команды». Коротко:

```bash
npm install
npm run tauri dev
```

Нужны Node.js 22, Python 3.12 и Rust (версия закреплена в `rust-toolchain.toml`).

## Готовые сборки

**[Скачать последнюю версию](https://github.com/mikhailsharov-arch/GenMetric/releases/latest)** (1.0.1) — Windows 10 и 11, macOS на процессоре Apple.

Тестовая сборка между версиями — по ссылке [latest-test](https://github.com/mikhailsharov-arch/GenMetric/releases/tag/latest-test): она обновляется автоматически после каждого изменения в коде. Как установить и что делать с предупреждением системы о неизвестном разработчике — в [инструкции](docs/установка.md).

Скомпилированные файлы в репозитории не хранятся — только в разделе выпусков, и собираются автоматически из исходного кода.

# Иконка программы

Рисунок — **Роман Чистов** (раскрытая книга с квадратиками на синем
#1F4E79), прислан 17.10.2026; исходник — `icon-source.png` (1920×1920).
До 20.10.2026 иконку рисовал скрипт `make_icons.py` — он убран.

Все размеры собираются из исходника одной командой из корня репозитория:

    npx tauri icon src-tauri/icons/icon-source.png -o /tmp/icons

Из папки `/tmp/icons` в эту папку кладутся только те файлы, что названы в
`tauri.conf.json` (`bundle.icon`): `32x32.png`, `128x128.png`,
`128x128@2x.png`, `icon.icns`, `icon.ico`, а также `icon.png`.

# Ресурсы, встраиваемые в установщик

Сюда попадает `seed.sqlite` — стартовая база справочников, которая ложится внутрь установщика и при первом запуске копируется в папку данных пользователя.

Файл собирается и в репозитории не хранится:

```bash
python3 db/build_seed.py src-tauri/resources/seed.sqlite
```

Этот README нужен ещё и для того, чтобы папка существовала в свежем клоне: git не хранит пустые каталоги, и без него сборка падала на первом же шаге.
